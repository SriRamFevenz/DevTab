01 /

commands

Everything starts at the prompt. Type a link name to fuzzy-find it; Tab completes and Enter opens. The rest are commands.

DEVTAB(1)v1.0.0Chrome
Prompt commands
inputdoes
<text> Fuzzy-find a saved link. Tab completes, Enter opens.
g gh so yt mdn npm shodan edb <query> Search that site.
cve 2024-3094 Open the NVD entry. Any other argument searches NVD.
add <url> [name] Add a link to the inbox group.
rm <name> Delete the best match. An undo toast appears.
theme <name> Switch theme: github matrix dracula nord amber cyber.
top Import Chrome's most-visited sites. This is the only command that reads the topSites permission.

keys

Keyboard shortcuts
/ or Ctrl+Kfocus the prompt

1–9open the numbered pinned link
?show help

links

Unlimited, grouped links. Drag to reorder or move between groups. Right-click to edit, pin, copy or delete.

      03 /
      
privacy

    

    

      
DevTab stores everything in chrome.storage.local and makes no network requests. The permissions are the part worth reading.

      

        

          
permissions requested

          

            
storage
Saves links, notes, snippets, targets, ports, and settings.

            
favicon
Shows site icons from Chrome's local cache.

            
topSites
Read only when you run top, to import Chrome's most-visited sites.

          

        

        

          
network

          
    
            
  • Network requests made by DevTab: 0.
    • 
            
  • Analytics: none.
    • 
            
  • Data location: chrome.storage.local, on this machine.
    • 
          

        

      

      
Nothing is synced or sent anywhere. Settings has JSON export/import for backups. Imports are validated; any non-http(s) link is dropped.

      
Security reports: read SECURITY.md. Do not open a public issue.

      ::
      
under the hood

    

    

      
The extension is Manifest V3 and small enough to read. There is no build step between these files and the new tab.

      

        

          

            files
            
          

          
newtab.html     page shell
css/style.css   themes and layout
js/main.js      links, prompt, keys, settings
js/workspace.js tools, notes, snippets, targets, ports, timer
js/codec.js     pure functions (encoding, hashing,
                URL safety, fuzzy search), unit tested
js/store.js     state, defaults, backup validation
js/ui.js        DOM helpers (text-only rendering, no innerHTML)
js/rain.js      optional background effect
test/           node:test suite

        

        
    
          
  • No build step, no dependencies.Vanilla JS and ES modules, loaded as they are.
    • 
          
  • Unit-tested core logic.js/codec.js holds the pure functions; npm test runs the node:test suite.
    • 
          
  • CI on every push.Tests and manifest validation run on every push and pull request. Tagged releases build a zip.
    • 
          
  • Text-only DOM.js/ui.js uses helpers, not innerHTML.
    •
