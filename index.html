Everything within reach of the prompt

Built for quick lookups, context switching, and the small jobs you would otherwise open five tabs for.

>_

Prompt-first

Fuzzy-find any shortcut, complete with Tab, and run site commands like gh, so, mdn, or cve.

[]

Grouped links

Unlimited groups with drag-to-reorder, pinning, and right-click edit, copy, or delete. Import your most-visited sites in one command.

{}

Workspace tools

Base64, URL, hex, and HTML entities, JWT decoding, MD5/SHA hashing, timestamps, JSON formatting, regex testing, and random strings.

#

Notes and snippets

An autosaved scratchpad, reusable commands, a target tracker, saved localhost ports, and a focus timer that only runs while a tab is open.

~

Six themes

GitHub, Matrix, Dracula, Nord, Amber, and Cyber. Switch from the prompt with theme <name>.

[x]

Private by default

Everything stays in chrome.storage.local. No accounts, no sync, no analytics, and no network requests of its own.

Install in under a minute

DevTab is a Chrome extension with no build step. Load it unpacked from source today.

Download latest release Read the guide

Chrome Web Store: a listing is planned. Until then, use the unpacked install below or grab a zip from Releases.

  1. 1

    Open the extensions page

    Go to chrome://extensions and turn on Developer mode.

  2. 2

    Load the folder

    Download and unzip the latest release, or clone the repository, then click Load unpacked and select the DevTab folder.

  3. 3

    Open a new tab

    Chrome may ask you to confirm keeping the extension's new tab page. Then press / and try help.
